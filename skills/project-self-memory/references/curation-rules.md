# Curation rules

只收录可复用、已验证的项目事实、长期决策、约束和可复现避坑。新结论若与既有记录等价则更新或合并；冲突、分组取舍、删除和负向评分必须讨论并确认。正文以可公开最小事实表述，删除凭据和个人信息。

Trim 候选是 `positive - negative < 0`，或 `negative >= 3 && negative >= positive`。证据不足只标注未证实并保留，不因旧、无关或暂未核验删除。

## 候选先落 cache

自动流程产生的新结论与投票先暂存在 `.project-self-memory/cache.jsonl`，不直接写记忆库。等价的新结论以 `update` 候选暂存；合并由人工执行 `merge`（`--keep` 必须是较早的 ID），自动流程不合并。

人工策展的 `-g`、`-r`、`-t` 不读 cache，只扫记忆库。cache 只由 `-c` 处理：`-c` 逐条询问后写入或丢弃，修改类候选必须展示原正文与新正文的对照。
