# Deep Investigation Protocol

## 1. 证据账本

为每个影响结论的事实记录：主张、发生时间、来源链接或标识、来源类型、是否一手材料、独立验证情况、事实等级和证据缺口。

事实等级按强至弱标注：已证实事实、高可信判断、未证实解释、当事方主张、弱证据传闻、当前未知。推断另标依据：公开表态、可观察行为、利益激励、合理推断或无证据猜测。不得把推断升级为事实。

来源优先级：原始文件、原始数据、完整采访、专业调查报道、高质量媒体、专家分析、社区线索。法规、法院、公司公告、财务文件和完整声明优先回到原文；社媒和摘要仅作线索。检查转载是否同源，且将无法取得的关键材料列入缺口。

## 2. 调查路径

1. 还原当前事件：确认发生了什么、谁受影响、哪些事实仍待确认。
2. 追查直接起因和历史根源：按解释力向前追溯，直到更早历史不再改变对当前事件的解释。
3. 标出形成、分裂、合并、替代、联盟、冲突、转向和衰退等改变路径的节点；时间线说明“此节点改变了什么”。
4. 仅保留能影响走向的主体，分析其角色、资源、诉求、约束和历史位置。
5. 建立关系图时，明确是隶属、控制、投资、合同、合作、竞争、联盟、依赖或冲突；每条关键关系附证据等级。合作不等于控制，接触不等于串谋。
6. 分别准确还原各方叙事，再比较支持证据、反证、来源质量和缺口；不以多数表决事实。

## 3. 协作与反证

可用子智能体时，主智能体分配互不重叠的检索问题：

- 事实分支：原始来源、时间线、历史根源。
- 关系分支：主体关系、资源与利益结构、阵营演化。
- 反证分支：竞争解释、来源独立性、反例与证据缺口。

分支不得把未验证中间结论作为其他分支前提。主智能体回到来源层解决冲突，比较证据质量，去除重复后综合。小型任务合并为事实历史与关系反证两支；无子智能体时按同样顺序串行执行。

## 4. 报告结构

按材料取舍下列结构，不为填满章节制造内容：

1. 核心结论：发生了什么、核心矛盾、为何重要；事实与分析分开。
2. 事实底稿与时间线：高置信事实及其证据性质、关键节点和变化。
3. 历史根源与分支演化：直接原因、结构背景、路径依赖；需要时使用文本树。
4. 关键主体与关系网络：角色、资源、诉求、约束、关系及证据等级。
5. 各方叙事、证据冲突与竞争解释：最强解释及其反证边界。
6. 未解问题与后续演化：说明还需要何种证据；以触发条件、阻力、领先指标和失效条件做情景分析，不给无依据的精确概率。
7. 来源证据：按重要性列出，并标注一手、二手或线索来源及独立性。

收尾时按“确定、较高可信、仍有争议、当前未知”归类，并指出最容易误导读者的叙事及其证据问题。
