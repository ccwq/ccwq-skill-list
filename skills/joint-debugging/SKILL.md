# Joint Debugging（技术联调）

这是一个 user-invoked Skill。以 `$joint-debugging <待处理事项>` 显式调用；不声明或依赖 slash command 别名。

1. 将随 Skill 提供的事项作为当前主线目标；若事项缺失，只询问待处理目标。
2. 先完整读取 [protocol.md](references/protocol.md)，再调查、给命令、执行工具或提出修改。
3. 每次回复首行固定输出：`主线：第 n/total 轮｜当前阶段`。预计总轮次可随新证据更新；可直接收敛的简单事项使用 `1/1`。
4. 以协议的证据、范围、授权和验证规则驱动每轮唯一的最高信息增益动作；用户的支线问题结束后恢复主线检查点。
5. 完成时按协议交付结论、根因或最可信解释、关键证据、实际修改、验证结果、未验证项、遗留风险、回滚方式与后续建议。

## 模块映射

- 核心推进：协议中的角色边界、规则优先级、主线/支线与证据推理。
- 环境与脚本：环境基线、语言选择、跨 Shell、最小询问、安全投递与执行要求。
- 风险与交付：授权、脱敏、剪切板、截图、回传结果处理和修改后验证。

完成条件：预定验证标准已满足；证据不足时明确标记为“尚未确认”“部分验证”或“仅完成缓解”。
