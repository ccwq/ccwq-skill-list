# 安装与回滚

## 决策与来源

分别确认二进制范围与交互配置范围。默认保留 shell 和 cd 语义，接管 cd 需单独授权。系统安装身份与配置账号/HOME/属主单独记录；提权交接遵循 [环境与交接](environment-handoff.md)，不静默将全局需求改为用户级。

## 先分类，再动作

| 实际状态 | 动作 | 完成证据 |
|---|---|---|
| 已装且满足接口需求 | 复用，跳过安装 | 版本/能力、来源与路径；暂存归档存在时可逐文件比较 |
| 已装但不足、不完整或路径冲突 | 报差异，先获升级/替换授权 | 原文件保护、目标版本收益和回滚方案 |
| 明确缺失 | 按需安装 | 包管理状态与目标路径检查 |
| 未知、探针覆盖不足 | 补查，不算缺失 | 查目标账号PATH、包清单、用户安装位置 |

“目标目录存在”应触发分类，而不是直接删除或机械报失败。摘要匹配仅证明所比较内容一致；还需检查文件类型、属主及使用能力。复用时不再次执行历史补丁。

按 OS/架构/发行版查候选包所带接口与集成文件。能满足需求就复用，不要求统一最新版。fzf 历史版本不一定支持 `--bash`，但独立快捷键脚本可能满足需求；快捷键脚本存在不证明同时附带 Bash 模糊补全脚本。对 zoxide 等实际检查 `init` 能力，不凭版本老旧推断缺失。不要从历史说明里的版本号、release 名称或 memo 文件推断当前 master 版本。

优先发行版可信包或官方发布物。下载第三方镜像只是传输选择：校验官方可信渠道的 SHA-256/签名或其他发布认证；校验依据也来自同一不可信镜像时注明信任限制。归档列表检查与大小只能发现损坏/截断，不能认证来源。未核验来源时不直接执行 root 级二进制。网络速度属即时事实，不能沿用历史测速作为保证。

## 安全变更

- 拍摄所需配置基线、权限与哈希；保护备份及可能含秘密的配置，不整段输出。
- 唯一临时目录存下载/测试结果；检查绝对路径、路径穿越、链接与归档内容，再解包。失败即停，清理局限于本次创建的目录。
- 原子替换已验证配置；锚点唯一性或标记块精确替换，不按历史行号插入。冲突先报告。
- 全局 profile.d 文件可能被非 Bash 读取，Bash 专属代码放独立 Bash 文件；入口用 POSIX 兼容的 shell/交互模式检查再委派。非交互路径不加载编辑器。
- 加载顺序按官方版本接口与已有插件实测确定，不机械照搬某台主机。避免重复 hook，成功后才置加载标记。ble.sh source 失败时不继续调用不存在的 `ble-attach`。
- fzf 与 ble.sh 集成使用目标版本官方适配方式，不编造 `fzf-history-widget` 等名字。需要的用户配置晚加载时，不能靠过早设置的单一哨兵跳过它。

## 精简系统与首次登录

遇 BusyBox、musl、默认 ash 或路由系统时先读 [精简 Linux 分支](minimal-linux.md)，处理包来源、启动入口、目录继承、临时/runtime空间及基线输出差异。

包数据库列出文件不等于磁盘实际存在。先核对目标版本声明的运行依赖与真实启动错误；精简系统连 `ps` 等常见工具也可能缺失。检查将要 source 的文件可读、内容与包版本匹配；缺失时查包管理器排除规则（例如精简镜像排除文档目录）。确需恢复时，仅对必要集成文件设置保留规则并重装已选版本；记录规则与回滚，不据此升级整个工具或关闭全部精简策略。

共享只读 ble.sh 安装必须验证普通账号首次登录。按目标版本源码确定缓存回退规则；某些版本在 `${XDG_CACHE_HOME:-$HOME/.cache}` 不存在时退回安装树。以配置使用者身份创建需要的私有缓存上级目录，检查绝对路径、属主、目录类型及可写性；保留既有 XDG 选择，不将共享安装树设成所有用户可写。缓存创建也列入 manifest；回滚通常保留运行缓存，不删除用户后来产生的数据。

下载失败先看首个传输错误。容器可能继承宿主代理，但地址、协议与工具支持未必匹配；验证可达性、协议及直连对照后，仅调整授权作用域。apt 的“不支持代理”可伴随误导性的 Release 文件错误，不能通过关闭签名校验处理。网络总耗时需有外层预算，单次连接超时并不限制持续低速传输。

## 回滚与验收

回滚计划区分本次新增、原有文件与用户后续改动。恢复前比较当前哈希；出现后续编辑时不要无条件整份覆盖。卸包只处理本次新增且获批准的包，不盲目 autoremove。先关闭接入块即可回退编辑器，不必删除全树。

保留一份**变更清单**作为安装与回滚的共同依据：

| 对象类别 | 最小记录 | 回滚边界 |
|---|---|---|
| 包/上游发布物 | 来源、版本、校验依据、原有或新增 | 只处理本次新增且获准移除的对象；不自动autoremove |
| 配置/额外登录入口 | 绝对路径、原始存在性、原/现摘要与权限、备份 | 无后续漂移才恢复原内容或原始不存在 |
| 缓存/runtime/临时目录 | 路径、属主、权限、创建者、持久或易失、重建责任 | 默认保留运行数据；清理单独授权，不递归清理用户既有目录 |
| 容器/验证资源 | 引擎连接、ID/标签、创建范围、保留原因 | 按精确资源清理，不按泛化名称批量匹配 |

每项标记 `planned / applied / verified / rolled_back / retained`，未执行项不写成完成。配置夹具自己的manifest只是该清单的一个子集；额外.bash_profile、包和runtime不因夹具返回rolled back就视作已撤销。包管理器提示“需重启”与真正重启分别记录。

**完成标准：** 实际写入对象都能在清单找到归属、恢复或保留方式；无需为这个记录协议扩展通用安装器。

语法、候选、真实按键、非交互回归逐层验收；失败停止升级后续阶段。远程临时文件与本地临时文件分别清理，遵守项目批量删除确认约束。
