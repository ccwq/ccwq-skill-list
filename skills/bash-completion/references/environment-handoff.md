# 环境选择与提权交接

## 身份契约

在操作前记录：`环境标识 / 连接入口 / 当前执行身份 / 安装身份 / 配置账号 / 配置HOME / 文件属主 / 安装范围`。未知字段先查询，不把历史例子当默认。

安装者可能是管理员，使用者可能是普通账号。系统工具和用户配置分阶段处理；获取目标账号HOME须在其上下文或系统账号数据库核实，不使用 sudo 后的 `$HOME` 猜测，也不要求用户发送密码。

## 环境分支

- **本机 Unix：** 核对实际账号、Bash 路径和系统版本。
- **WSL：** 先枚举发行版和状态；有歧义时请用户选择，再在选定环境检查默认账号。停止的环境启动前说明影响。命令示意中的 `DISTRO`/`ACCOUNT` 都是现场参数：`wsl -d DISTRO -u ACCOUNT --exec ...`。不将其他虚拟机/容器环境视为用户目标。
- **远程：** 使用项目授权入口；主机与账号明确后再连接。本仓库按 [项目适配](project-adapter.md)。

PTY 工具在已选定环境内部运行，不负责枚举发行版、SSH、切换账号或提权。Windows 原生不支持其Unix PTY接口时报告 unsupported，在获授权的WSL环境运行，不自动安装运行时。

## 手动提权交接

当 sudo 需要用户交互时停在关口：让用户选择手动执行或另行授权的提权方式。PTY 验证器不用于输入 sudo 密码。

使用下列**交接单模板**生成一个针对当前任务的脚本，而非通用安装器：

```text
目标环境：<已确认环境>
安装身份：<管理员身份>；配置使用者：<账号及核实HOME>
输入：<可信来源、固定版本/提交、摘要/签名与信任边界>
写入：<精确系统路径或包清单>；不写入：<用户启动配置等>
状态判断：满足则复用；冲突停止；缺失安装
失败行为：停止后续阶段、保留诊断；仅清理自己创建的临时目录
回滚：<此次新增文件/包或配置的精确逆操作>
用户命令：sudo bash -- '<目标环境可访问的脚本绝对路径>'
完成标记：<仅在安装与校验成功后打印的唯一标记>
```

脚本要求：语法先验、捕获实际退出码、root要求与目标身份校验、固定可信输入、已有目录保护。特权执行前把暂存输入复制至 root 所有的独立临时目录再校验/解包，拒绝越界路径和不支持的特殊文件。脚本不在 root 下 source 新装的交互编辑器。

用户可先审阅再执行；以现场路径替换模板，不让未替换占位符成为可执行命令。脚本集中放目标环境的用户状态/临时目录，不散落项目脚本目录。

用户返回后独立复核安装状态，而不是仅相信日志最后一行。遇到“目录存在”按安装三态核对；一致则继续用户配置，不要求重装。验证完成后按授权清理下载/脚本，保留最小manifest和回滚备份。

## 网络与可信性

WSL 内的 localhost 不必然指向 Windows 代理；先观察网络模式及端口可达性，再选择传输。API 与附件重定向可能是不同域名，要分别验证。必要时经授权在宿主下载官方HTTPS发布物后传入目标环境并比对摘要。

本地计算的摘要只能验证传输/内容一致性，不应称为发布者签名。来源选择与认证原则统一见 [安装回滚](installation-rollback.md)，不把某个镜像地址或历史测速写作永久保证。
