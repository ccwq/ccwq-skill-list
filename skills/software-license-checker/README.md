# Software License Checker

为企业内部使用的软件提供偏保守的许可证、商业授权与潜在付费预警，并把公开采购信息整理给技术负责人和采购。它是公开信息基础上的合规预警，不构成正式法律意见。

## 适用范围

仅适用于公司内部安装、研发、测试、办公、数据处理、运维辅助和不对外提供服务的内部系统。SaaS 对外服务、嵌入产品后的外部分发、OEM、转售和外部开源义务分析不在此范围内。

```text
$software-license-checker 公司内部使用某软件是否需要商业授权？
$software-license-checker 检查 <软件名称或官网链接> 的内部使用合规与付费方式
```

根 [README](../../README.md) 保留触发与参数速查。

## 需要提供什么

优先提供软件名称、官方仓库或官网、目标版本，以及是否确实只在企业内部使用。只有版本、同名项目或实际使用方式会改变结论时，Skill 才会追问。

## 如何得出结论

调查优先使用官方许可证文本、官方 FAQ、版本说明、商业授权页和价格页，并明确来源与适用版本。结论只有三档：

| 结论 | 含义 |
| --- | --- |
| 低风险 | 当前证据下，目标版本通常可用于企业内部使用，未发现明显附加限制 |
| 高风险 | 有明确限制、商业授权要求或条款冲突，需要先处理授权 |
| 信息不足 | 版本、条款或来源不足，不能保守地给出低风险结论 |

信息不足不会被表述为“应该没问题”。

## 授权与付费整理

只要发现商业版、企业版、席位/按量计费、试用限制、公开折扣或“联系销售”，报告都会额外给出“授权与付费整理”。该附录区分公开价格、公开优惠和未公开项；对企业报价不会猜测。

默认以中国团队采购视角整理购买路径、币种与是否需要联系销售。

## 输出与边界

主报告会用大白话说明“能不能内部用、前提是什么、主要风险是什么”，并附上核心依据、风险提示和免责声明。长期关键依赖、采购成本高或证据冲突的情况，应交由法务或知识产权律师复核。

完整证据优先级、风险量表、付费证据规则和报告模板见 [SKILL.md](SKILL.md) 及 `references/` 目录。
