# WhisperX：能力分支与简单用例

资料核对日期：2026-11-03。以下用例是建议路线，未作为完整工程运行验证。API 和安装写法按项目锁定版本再次核对。

## 前提与输入输出

Python、转写/对齐模型；GPU 或 CPU 路线不同。输入录音，输出文本、时间戳和可选说话人标签。

## 主要能力树

每行是一条能力分支。先按任务找到分支，再用入口查官方细节；不把所有入口视作同一版本、模型或后端均可用。

| 能力分支 | 功能 / API / 文档入口 | 简单用例 |
| --- | --- | --- |
| 语音转写 | load_model、load_audio、model.transcribe | 把旁白转为带片段结构的文本 |
| 语音切段 | VAD 与批量转写配置 | 长录音按语音活动切段，减少静音干扰 |
| 精细时间对齐 | load_align_model、align | 把识别词对齐到音频，为逐词字幕提供时间 |
| 说话人分离 | DiarizationPipeline、assign_word_speakers | 访谈中给词分配说话人标签 |
| 语言与领域 | language、alignment 模型、上下文选项 | 技术旁白先确认语言，校正专名 |
| 输出与部署取舍 | CLI writers、batch_size、compute_type、device | 导出字幕/JSON，显存不足时先减批量 |

## 最小实现路径

短录音转写 → 核对文本 → 语言匹配对齐 → 必要时分离说话人 → 导出时间数据 → 合成字幕。

## 展开用例：逐词高亮字幕

输入干净旁白；输出文本、词起止秒和渲染字幕。

transcribe → 校对文本 → load_align_model/align → 导出词时间 → 合并为可读字幕组 → 渲染端根据当前时间高亮。

关键参数与验收：先调语言、批量大小和字幕分组规则；数字缺词时间时保留片段时间或人工修正。WhisperX 不负责最终视觉设计。

## 边界与常见问题

对齐不替代内容校对；数字和特殊符号可能缺少词时间，重叠发言和分离结果须复核。分离模型可有独立访问条件。

当前 README 记录 ASS 导出在 v3 移除。需要逐词样式时，从对齐 JSON 自行生成 ASS 或交给画面框架绘制；不要承诺直接导出所需样式。中文“词”的分组须按实际对齐单位检查，再合并成适合阅读的词组。

## 验证

试听抽查词起止、人名、数字与换人位置；字幕格式不代表已烧录进视频。
