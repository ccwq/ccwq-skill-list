# LosslessCut：能力分支与简单用例

资料核对日期：2026-11-03。以下用例是建议路线，未作为完整工程运行验证。API 和安装写法按项目锁定版本再次核对。

## 前提与输入输出

桌面软件与已有媒体文件。输入音视频/字幕轨道，输出复制流剪切或封装后的文件。

## 主要能力树

每行是一条能力分支。先按任务找到分支，再用入口查官方细节；不把所有入口视作同一版本、模型或后端均可用。

| 能力分支 | 功能 / API / 文档入口 | 简单用例 |
| --- | --- | --- |
| 选段与分割 | Segments、in/out、导出模式 | 保留长录屏中的三段有效演示 |
| 片段与文件合并 | Merge；兼容编码/流参数 | 把相同参数的若干录制片段合为一条 |
| 轨道管理 | Tracks；提取/替换/删除 | 移除多余麦克风轨，保留应用音 |
| 重新封装 | 输出容器设置/remux | 在编码兼容条件下换容器而不重编码 |
| 标记与结构 | Markers、chapters、CSV/EDL 导入导出 | 用实验事件时间表标出待截取片段 |
| 辅助检测 | 场景、黑帧、静音检测 | 先生成候选切点，再人工确认 |
| 信息与导出 | metadata、rotation、snapshots、CLI/HTTP API 文档 | 修正旋转元数据，或取关键帧作封面 |

## 最小实现路径

导入原片 → 检查轨道 → 标片段 → 选择导出模式/容器 → 导短段 → 复核切点与同步。

## 展开用例：从录屏保留两个片段

输入长录屏；输出选中片段的合并文件。

标两组 in/out → 确认保留而非删除模式 → 检查轨道 → 按支持模式导出合并 → 核对两处切点。

关键参数与验收：先确认切点精度需求与关键帧；若必须任意帧精确，评估重编码而不是承诺复制流能做到。

## 边界与常见问题

无损切点受关键帧和模式影响；不保证任意帧精准。更换容器不改变编码能力，不承担复杂叠画和字幕烧录。

## 验证

对照所选切点检查首尾、时长和音轨；使用目标播放器验证封装兼容。
