# Remotion Skills：能力分支与简单用例

资料核对日期：2026-11-03。以下用例是建议路线，未作为完整工程运行验证。API 和安装写法按项目锁定版本再次核对。

## 前提与输入输出

供智能体读取的规则集。输入创作需求和项目，输出实现指导、工程操作或渲染操作的规范；实际动作依赖 Remotion 环境及客户端能力。

## 主要能力树

每行是一条能力分支。先按任务找到分支，再用入口查官方细节；不把所有入口视作同一版本、模型或后端均可用。

| 能力分支 | 功能 / API / 文档入口 | 简单用例 |
| --- | --- | --- |
| 综合规则 | remotion-best-practices | 不知道应读哪份规范时从总入口选分支 |
| 项目创建 | remotion-create | 新建宣传片 composition 并定义规格 |
| 画面与时间轴 | remotion-markup | 查布局、字体、动画和媒体编排要求 |
| 预览与出片 | remotion-studio、remotion-render | 分别启动预览和导出样片 |
| 地图与字幕 | remotion-maps、remotion-captions | 路线动画或逐词字幕场景读取专项规则 |
| 产品集成与编辑 | remotion-saas、remotion-interactivity | 设计批量渲染服务或可编辑合成 |
| 资料查询 | remotion-docs | 查当前官方参数和示例 |

## 最小实现路径

核对当前仓库目录 → 读取匹配子技能 → 在 Remotion 项目应用规则 → 用工程命令预览或渲染。

## 展开用例：给已有视频增加逐词字幕

输入现有合成和词时间数据；输出字幕实现路线与改动。

读取 remotion-captions → 按需读 remotion-markup 的时间/文字规则 → 应用到合成 → remotion-studio 预览 → remotion-render 样片。

关键参数与验收：以当前目录实际存在的子规则为准；检查是否正确处理秒/毫秒/帧，不以成功安装规则包作为验收。

## 边界与常见问题

这些是上游技能名，不保证当前客户端安装后能以相同斜杠命令调用。规则包不会替代渲染器；未安装时可以查官方资料，不冒称已调用技能。

## 验证

指出读取的子规则和用于解决的具体任务；运行验证由实际项目记录支持。
