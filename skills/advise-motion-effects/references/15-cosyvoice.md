# CosyVoice：能力分支与简单用例

资料核对日期：2026-11-03。以下用例是建议路线，未作为完整工程运行验证。API 和安装写法按项目锁定版本再次核对。

## 前提与输入输出

按模型版本准备 Python、推理依赖与权重。输入文本及可选授权参考音频，输出语音波形或分块音频。能力按模型代际区分。

## 主要能力树

每行是一条能力分支。先按任务找到分支，再用入口查官方细节；不把所有入口视作同一版本、模型或后端均可用。

| 能力分支 | 功能 / API / 文档入口 | 简单用例 |
| --- | --- | --- |
| 基础配音 | SFT/预置说话人推理；仓库示例 | 先生成一句标题旁白，检查数字与术语 |
| 参考声音 | zero-shot 推理分支 | 用授权参考声音给新文案配音 |
| 跨语言 | cross-lingual 分支 | 按模型支持用同一声线输出另一语言 |
| 表达控制 | instruct 分支 | 尝试语速、情绪或方言指令并试听 |
| 发音与文本控制 | 模型支持的发音修补、文本规范化 | 处理人名、数字、英文缩写的读法 |
| 流式与服务 | streaming、runtime 的服务端/客户端 | 收到文本后连续发送语音块 |
| 适配与训练 | examples 下训练与推理流程 | 在有数据和资源时评估领域适配 |

## 最小实现路径

选模型及对应示例 → 准备文本/参考声音 → 短句推理 → 听音修正文案或指令 → 按真实时长排画面。

## 展开用例：技术旁白短句验证

输入一句带数字与术语的文案；输出 WAV。

核对模型与 example.py → 选择对应说话人/参考声音/指令分支 → 合成短句 → 试听修正文案或控制信息 → 保存音频及采样率。

关键参数与验收：先调句子拆分、参考文本一致性和模型支持的语速控制；根据真实时长排画面，不先承诺严格秒数。

## 边界与常见问题

不同代际不保证提供相同推理函数或 instruct 能力。参考音频采样率、文字和实际读音须对应。不要直接照抄旧版路径或延迟宣传值。

## 验证

试听遗漏/重复、术语、噪声和停顿；输出采样率和时长以文件为准。
