# ComfyUI：能力分支与简单用例

资料核对日期：2026-11-03。以下用例是建议路线，未作为完整工程运行验证。API 和安装写法按项目锁定版本再次核对。

## 前提与输入输出

节点图运行环境、所选模型与依赖。输入提示词、图像或其他媒体，输出生成素材；每种能力依赖具体模型与节点。

## 主要能力树

每行是一条能力分支。先按任务找到分支，再用入口查官方细节；不把所有入口视作同一版本、模型或后端均可用。

| 能力分支 | 功能 / API / 文档入口 | 简单用例 |
| --- | --- | --- |
| 基础图像生成 | Checkpoint/模型加载、文本编码、采样、VAE、保存节点 | 生成背景图，记录 seed 与模型 |
| 图像编辑与局部重绘 | 图像/遮罩、对应编辑或 inpaint 工作流 | 保持主体，替换指定区域 |
| 结构控制与风格 | ControlNet、LoRA、适配器类工作流 | 用姿态或深度约束构图，调整已支持的风格 |
| 视频与声音 | 官方视频/音频模板 | 按模型支持执行文生视频、图生视频或音频生成 |
| 放大与修复 | upscaler、修复类工作流 | 提高素材尺寸，再检查细节一致性 |
| 3D 与视觉分析 | 官方 3D/vision 模板、Partner nodes | 生成候选模型或提取深度供后续环节使用 |
| 复用与自动化 | workflow JSON、subgraphs、queue、local API | 模板只替换提示词批量出图 |
| 资源与扩展 | partial re-execution、模型管理、自定义节点 | 只重跑变化分支，隔离第三方依赖 |

## 最小实现路径

从匹配模型的官方模板开始 → 核对节点/权重 → 用小尺寸生成 → 保存工作流与 seed → 检查素材 → 接下一环节。

## 展开用例：生成可复用背景素材

输入提示词与选定模型模板；输出背景图和工作流。

加载官方模板 → 核对 checkpoint/VAE/文本编码器 → 小尺寸少量采样 → 保存图像与工作流 → 锁定候选图导入视频工程。

关键参数与验收：先调尺寸、seed、采样设置和模型支持的引导参数；固定模型/节点版本，检查文字、主体和构图。

## 边界与常见问题

框架能力不保证每台设备支持所有模型。UI 工作流与 API 格式按当前接口转换。固定 seed 不保证跨模型/设备逐位相同；Partner 节点可涉及远程提交与费用。

## 验证

工作流重开后节点齐全；模型和版本明确；输出可被剪辑或渲染环节读取。
