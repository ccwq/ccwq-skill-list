# MCP for Blender：能力分支与简单用例

资料核对日期：2026-11-03。以下用例是建议路线，未作为完整工程运行验证。API 和安装写法按项目锁定版本再次核对。

## 前提与输入输出

第三方桥接插件；Blender、本机插件服务、MCP 服务与客户端都须连通。输入自然语言或 Blender Python，输出场景改动、截图或渲染文件。

## 主要能力树

每行是一条能力分支。先按任务找到分支，再用入口查官方细节；不把所有入口视作同一版本、模型或后端均可用。

| 能力分支 | 功能 / API / 文档入口 | 简单用例 |
| --- | --- | --- |
| 场景检查 | 场景信息与视觉验证工具 | 读取现有对象、材质与镜头，再提出修改 |
| 对象操作 | 对象创建/修改工具、Blender Python | 搭建产品转台并调整尺寸与位置 |
| 材质与布光 | 材质工具、Blender Python | 给零件指定粗糙度，摆放主光与补光 |
| 镜头与动画 | Blender Python、关键帧与场景设置 | 围绕产品转镜头，渲染短片检查运动 |
| 多角度验证 | 截图、线框、X-ray、渲染检查 | 确认遮挡、比例和隐藏几何 |
| 外部素材与生成 | Poly Haven、Sketchfab 及模型服务集成 | 导入环境贴图或生成模型后再整理；服务依赖单独核实 |
| 工程与输出 | Blender 保存、渲染和导出接口 | 保存副本，按目标格式导出模型供网页验证 |

## 最小实现路径

确认连接 → 读取场景 → 保存工作副本 → 进行一个小改动 → 用截图验证 → 扩展到整段场景。

## 展开用例：创建简单产品转台

输入空场景与产品资产；输出场景副本和短片。

连通后读取场景 → 导入资产并检查单位 → 摆相机与灯光 → 经 Blender Python 插入旋转关键帧 → 先渲两个静帧 → 渲染短片。

关键参数与验收：先调镜头焦距、物体转速、帧起止和输出尺寸；把桥接工具返回状态与实际渲染结果分别检查。

## 边界与常见问题

具体 MCP 工具名以当前服务发现为准。底层 Blender 能力不等于桥接提供独立工具；动画/导出可经 Python 操作。外部服务可涉及费用和上传。

## 验证

检查 Blender 场景对象与渲染文件；连接成功本身不代表作品正确。
