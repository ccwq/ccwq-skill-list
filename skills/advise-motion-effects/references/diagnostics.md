# 排障路径

先记录复现动作、实际/预期、版本与目标设备。下表是待检验假设，不是对用户工程的诊断结论。每次只改一个有区分作用的变量。

| 现象 | 最小检查 | 下一步取决于什么 |
| --- | --- | --- |
| 元素完全不动 | 检查目标是否存在、初终值、触发事件、容器尺寸 | 找不到元素先修生命周期；事件没触发先修事件 |
| Vue/React 状态变了但退出没播 | 检查 key、Presence 包裹、条件渲染和节点保留 | 确认退出组件实际存活再查动画参数 |
| 滚动时反复抖动或重播 | 区分 in-view 触发与连续 progress；检查实例数量 | 检查是否每次滚动创建新实例或重置状态 |
| 动画卡顿 | 录性能轨迹；分别关闭布局动画、后期、粒子 | 根据 CPU、布局/绘制或 GPU 压力选优化；不只看平均 fps |
| Three.js 黑屏/模型不见 | 最小网格；检查相机、尺寸、加载错误、灯光和缩放 | 几何正常则逐步恢复模型/材质/后期 |
| 颜色发灰、发光过曝 | 去掉后期，检查色彩空间、色调映射和缓冲精度 | 每次恢复一个效果，保持渲染链一致 |
| 路径追踪一直有噪点 | 固定相机与场景，检查采样是否增长、是否反复 reset | 静止正常则查变更触发；再评估采样/降噪 |
| 粒子速度依赖显示帧率 | 检查 delta 单位及重复 update | 时间统一后再调寿命/速度，不靠增加帧率掩盖 |
| 刚体穿透或抽搐 | 独立地面/球测试，核对形状、尺度、固定步长、碰撞层 | 按结果检查连续碰撞或约束；不先调渲染器 |
| 路由来回后更慢 | 比较循环、监听、粒子实例及 GPU 资源数量 | 按所有权清理；共享资源不能随单组件任意 dispose |
| 配音/字幕逐渐漂移 | 比较原始秒时间、裁切偏移、fps、sr/hop_length | 固定偏移与累积误差分别修，不统一拉伸时间掩盖 |
| 字幕有字但没有词时间 | 检查语言对齐模型和不在字典内的字符 | 人工校正或回退片段时间；不伪造词精度 |
| ComfyUI 缺节点/权重 | 核对工作流和当前安装的节点/模型版本 | 使用可信对应依赖或替换匹配模板 |
| OBS 黑屏/无声/卡顿 | 单源录制，检查捕获权限、路由及 Stats | 渲染滞后与编码滞后分别调整 |
| 无损剪切首尾不精确 | 检查关键帧、剪切模式、实际输出时间 | 接受关键帧切点或改走重编码精准裁切 |
| FFmpeg 成功但结果不对 | ffprobe 对比输入输出的流、时间和尺寸；播放样片 | 先排选轨和时间作用域，再排滤镜/编码 |
