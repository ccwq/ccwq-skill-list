# 组合与时间契约

这些是工程设计起点，非已运行的统一流水线。先写清输入输出，再构造一个短镜头验证交接。

## 最小交接字段

| 数据 | 必须写清 | 例子与检查 |
| --- | --- | --- |
| 视频时间 | 秒/毫秒/帧，fps，起点，区间是否含结束点 | 旁白事件 1.2 秒，在 30 fps 上映射为第 36 帧；确定取整策略 |
| 音频特征 | sr、hop_length、center、时间单位 | beats_seconds 与 rms_times，不能将数组下标直接当帧号 |
| 字幕 | start/end 单位、text、可选 speaker/words | 用秒保存词时间，高亮时检查 start <= t < end |
| 三维资产 | 单位、坐标轴、材质/贴图、动画片段、加载路径 | Blender 输出 GLB 后在实际 Three.js 场景检查比例与材质 |
| 物理状态 | 固定步长、单位、位姿、渲染插值与事件 | 物理世界更新后同步网格，碰撞事件只触发一次爆发 |
| 粒子和随机性 | seed 支持、delta、寿命、是否依赖历史状态 | 实时粒子逐步模拟；离线跳帧须预模拟或记录缓存 |
| 图像与成片 | 分辨率、颜色/alpha、帧率、编码、音轨 | 透明素材是否预乘、输出是否支持透明均需核对 |
| 配置复现 | 包/模型/节点版本、素材、参数与来源 | Tweakpane 面板状态之外保存真正控制场景的数据 |

## 网页叙事与组件动效

项目状态→Motion；多对象时间编排→Anime.js；只有存在三维内容时再加入 Three.js。先选负责同一元素属性的唯一驱动者。组件挂载后创建实例，卸载时撤销监听和动画。Vue 缓存路由中区分 onDeactivated/onActivated 与真正 onUnmounted：前者暂停/恢复，后者销毁；激活时不得重建第二条循环。

分别验证滚动进入/退出、快速反向、路由切换、resize、减少动态效果与触摸交互。

简单用例：滚动到产品段落时卡片出现；段落内滚动持续推进三维模型角度。出现动作与连续进度分别管理，不反复重建三维场景。

## 浏览器粒子与交互场景

Three.js 场景→Three.quarks 发射器→按需加 postprocessing→Tweakpane 调参。需要刚体碰撞才接 Jolt。统一时间源：渲染 delta、粒子 delta 和物理固定子步明确换算。先验证没有后期的单次爆发，再增加发光和复杂贴图。

简单用例：球碰到地面时发出一次火花。Jolt 产出接触事件；业务逻辑过滤重复接触；Three.quarks 在接触位置发射；后期只加强画面；Tweakpane 调强度并保存参数。

## 写实三维与离线渲染

Blender 建模/材质→检查导出→Three.js 场景或 Blender 自身渲染。选择浏览器路径追踪时，先核对支持的后端与材质。每帧确定镜头状态，更新并重置累积，达到预设采样条件后捕获。动态粒子、透明材质和导入材质不是自动兼容项。

简单用例：产品旋转一周输出短片。先制作两个角度的静帧并对比材质，再扩到完整帧序列。不同帧的采样与降噪配置保持一致。

## 代码视频、公式与配音

画面主线选 Remotion 或 Manim。CosyVoice 文本→WAV→核对发音/时长→画面时间轴；需要字幕再用 WhisperX。数学精确图形由 Manim 表达，也可渲成素材后进入 Remotion。不要为同一个普通片头同时维护两个渲染框架。

简单用例：一条公式拆三步。先写每步解释，配音确定真实句长；Manim 控制图形变形；镜头区间与句子相配；最后合成并检查字幕。逐词高亮的数据转换、中文分组与版面由工程实现；WhisperX 不是字幕动画渲染器。

字幕烧录用 FFmpeg 或在画面主线中绘制，二选一避免重复。

## 音乐可视化

librosa→beats/onsets/features JSON→动画端。离散事件（切镜、爆发）和连续包络（缩放、发光）分开映射；连续信号先归一化、限幅，再平滑。时间映射保留原 sr/hop_length 与裁切偏移。没有稳定节拍的音频不强行把估计 BPM 当真。

简单用例：低频强度控制发光，鼓点控制火花。先用简单方块验证音画同步，再换成复杂特效。

## 生成素材与后期交接

ComfyUI 模板→检查模型/节点→小样→保存工作流→图像/视频资产→Remotion/Blender/FFmpeg。生成素材的帧率、尺寸和 alpha 与目标工程分别核对；需要时间一致性时先检查闪烁和主体漂移。

简单用例：生成三张背景图用于三段标题。图片生成完成后固定为素材，避免每次渲染时重新生成导致结果变化。

## 录屏、快剪与交付

实时作品→OBS→LosslessCut 选段→FFmpeg 按需转码。OBS 录制源与声音路由先检查；LosslessCut 适合保留原流；需要画面滤镜或精准重编码则选 FFmpeg。若代码渲染器已产生稳定成片，无额外录屏需求时跳过 OBS。

简单用例：录应用操作，保留两段，烧录字幕后交付。分别检查录制质量、剪辑切点与最终编码，追踪音轨是否在某步丢失。
