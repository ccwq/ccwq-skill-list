# OBS Studio：能力分支与简单用例

资料核对日期：2026-11-03。以下用例是建议路线，未作为完整工程运行验证。API 和安装写法按项目锁定版本再次核对。

## 前提与输入输出

桌面软件及操作系统的捕获权限。输入屏幕、窗口、摄像头、媒体或音频源，输出实时录制或直播。

## 主要能力树

每行是一条能力分支。先按任务找到分支，再用入口查官方细节；不把所有入口视作同一版本、模型或后端均可用。

| 能力分支 | 功能 / API / 文档入口 | 简单用例 |
| --- | --- | --- |
| 场景与捕获源 | Scenes、Sources；Window/Display/Game/Browser Capture | 只录演示窗口，叠加说明文字 |
| 画面构图 | 源变换、裁剪、滤镜 | 裁去窗口边框并将摄像头放到角落 |
| 声音路由 | Audio Mixer、Advanced Audio Properties | 应用音与麦克风分轨保存，避免重复捕获 |
| 切换与转场 | Studio Mode、Transitions | 先预览下一场景，再切到演示镜头 |
| 录制与编码 | Output、Video、Auto-Configuration Wizard | 选择画布、输出尺寸、帧率和编码器 |
| 直播与回放 | Streaming、Replay Buffer | 直播展示并保留刚发生的一段操作 |
| 诊断与扩展 | Stats、logs、插件与 WebSocket 文档 | 区分渲染滞后与编码滞后，按需自动切场景 |

## 最小实现路径

自动配置 → 加单个捕获源 → 确认音频路由 → 录短片 → 播放各轨 → 调编码和尺寸。

## 展开用例：应用声音与麦克风分轨录制

输入窗口与两种声音源；输出可分别编辑的录屏。

创建场景和窗口源 → 配实际音频源 → Advanced Audio Properties 分配轨道 → Output 配录制轨 → 录短片 → 检查每轨。

关键参数与验收：先调画布/输出尺寸、fps、编码和音量；系统混音若已包含麦克风，排除重复路由。

## 边界与常见问题

各平台捕获源支持不同。录制只保留实时表现；掉帧不会被导出自动补好。画布尺寸不等于实际输出尺寸。

## 验证

播放录制文件检查黑屏、音轨、同步与卡顿；Stats 检查渲染和编码丢帧。
