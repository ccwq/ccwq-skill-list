# FFmpeg：能力分支与简单用例

资料核对日期：2026-11-03。以下用例是建议路线，未作为完整工程运行验证。API 和安装写法按项目锁定版本再次核对。

## 前提与输入输出

已安装可用构建；先检查 ffmpeg/ffprobe 版本、编码器和滤镜。输入媒体流，输出处理后的媒体与探测信息。

## 主要能力树

每行是一条能力分支。先按任务找到分支，再用入口查官方细节；不把所有入口视作同一版本、模型或后端均可用。

| 能力分支 | 功能 / API / 文档入口 | 简单用例 |
| --- | --- | --- |
| 探测与选轨 | ffprobe、-map、-an/-vn | 检查时长/编码/帧率，再明确保留哪些流 |
| 转码与封装 | -c:v/-c:a、-c copy、容器设置 | 为播放器生成 H.264/AAC 样片，或仅换封装 |
| 裁切与连接 | -ss/-t、trim/atrim、concat | 截取演示片段；精准裁切和流复制分别选择 |
| 尺寸与画面 | scale、crop、pad、fps | 转竖屏并补边，控制输出尺寸 |
| 叠加与字幕 | overlay、drawtext、subtitles | 叠 logo，或把字幕烧录到画面 |
| 音频整理 | volume、amix、afade、loudnorm | 旁白混入背景音乐，淡出并调整响度 |
| 时间与速度 | setpts、asetpts、atempo | 演示加速并同步调整声音 |
| 序列与交付 | 图像序列输入、filter_complex、像素格式 | 把渲染帧合成视频，再检查目标播放器 |

## 最小实现路径

ffprobe 原片 → 确认流/时间基准 → 单个滤镜做短样片 → 明确编码/像素格式 → 播放验证 → 批量处理。

## 展开用例：视频配旁白后交付

输入无声视频、旁白；输出有声成片。

ffprobe 比较时长与流 → 明确 -map 选视频和音频 → 确认视频是否可复制、音频需否编码 → 生成短样片 → 检查流和播放器。

关键参数与验收：先定裁切/补静音/保留尾画面的规则；不能无条件用 -shortest。出现画面滤镜时重新编码视频。

## 边界与常见问题

滤镜通常需要解码重编码，不能同时承诺 -c copy。libx264、libass 等随构建不同。选项顺序有输入/输出作用域；文件名和滤镜字符串按系统正确转义。

## 验证

检查输出流、尺寸、帧率、时长和声音；画面与编码成功分别验收。
