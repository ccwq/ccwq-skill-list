# 时间与估算

长程任务或 spec 执行期间，每次简报都写时间行，包括立即简报、周期简报和收尾简报。短任务与一次性请求不写时间行。

## 总耗时

- 任务开始时刻有证据时，总耗时取「本次报告时刻 − 任务开始时刻」的墙上时间，包含等待与阻塞。
- 缺少任务开始证据时，只报告本次可观察到的时段，并写明覆盖范围，例如「总耗时 12 分钟（自本轮恢复起）」。
- 不得用简报启用时间代替任务开始时间。改周期、重新简报和会话恢复都不重置有证据的任务开始时刻。
- 等待时长只在有可靠起止记录时显示。出现较长等待时，另起一句写等待原因。

## 预计剩余时间

- 给区间，不给准点承诺。依据是剩余事项、依赖关系、验证工作和当前阻塞。
- 并行工作按依赖和可重叠部分考虑剩余时间。不累加各子 Agent 耗时，不用主观完成百分比反推。
- 缺少范围、估算依据或阻塞解除时间时，写「预计剩余：未确认」，并说明缺什么。
- 整体范围仍未确定时，估算只覆盖当前正在处理的事项，并写明该范围。
- 范围、依赖或阻塞变化后重新估算，并在下一次简报更新。

## 证据

- 宿主允许存储状态时，保存任务开始时刻与计时覆盖范围。
- 恢复时缺少计时证据就说明限制，不用推算值补齐。
