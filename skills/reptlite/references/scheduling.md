# 调度适配

只读取当前宿主对应分支。以下能力为 2026-11-13 官方文档调查所得；执行时以实际工具清单、版本、帮助及返回为准。文档有功能，不代表当前安装具有该功能。探测使用最小只读查询；工具缺失时说明，不修改全局配置或安装服务。

## 统一契约

- 保留同一任务、同一会话上下文；每个任务最多一个 reptlite 调度。绑定所属标识，仅管理自己的调度。
- 默认请求 2 分钟。创建、修改、停止后查询实际状态；记录精度、首次与下次时间、忙碌延迟及有效期。时区采用用户时区。
- 启用后让调度器自动执行已授权简报；这不等于允许模型自动触发技能。回调内容按 SKILL.md 的「调度回调内容」构造。
- 用户现有心跳、循环或任务属于其他用途时，保持原状。独占槽位被占用时报告冲突；有不覆盖原任务的可用后端则选择它，否则保留手动报告。不得默默替换。
- 每次周期回调只执行一次报告。避免重叠运行和漏触发补报风暴。发生延迟时报告实际时间，不伪造准点历史。
- 不把独立会话任务冒充当前会话监控。独立任务只有在状态来源、读取权限和投递目标均明确时才能使用。

## Claude Code

发现 `CronCreate`、`CronList`、`CronDelete` 时，使用原生会话 cron。2 分钟对应 `*/2 * * * *`；以工具实参 schema 为准，创建普通文本简报回调，记录返回标识。停止只删除所属标识。无修改接口时删除再建，并如实反馈部分失败。

`/loop 2m <普通文本简报指令>` 是宿主支持的用户入口，不是假定存在的 shell 命令。定时触发不能再次加载 `disable-model-invocation: true` 的技能，因此不得只安排 `/reptlite -i`。

告知限制：最小粒度 1 分钟；部分间隔会取整，必须在改变前说明并征得用户选择；cron 是墙上时钟匹配，不保证从创建时精确间隔两分钟；运行有偏移；忙碌时等待当前回合结束；循环任务有有效期。请求与宿主语义不完全一致时明确列出实际行为，尤其 `-r` 的下次触发时间。

来源：https://code.claude.com/docs/en/scheduled-tasks

## Codex / ChatGPT Work / 桌面

首先区分 CLI、IDE、桌面及 Work，查看是否实际暴露 automation/scheduled-task 创建、查询、更新接口。优先使用绑定当前聊天的分钟级调度；不要默认创建全新会话任务。按实际 schema 设置周期，保存返回标识，并回读。停止通常映射禁用，修改映射更新；确认本技能所属目标不变。

本地文件任务依赖机器和应用运行；网页任务不能自然访问用户电脑目录。分钟精度、当前聊天绑定、忙碌投递和恢复行为按实际接口核对，不能仅凭产品名保证。

CLI / IDE 官方不提供 Scheduled 管理界面。只有发现确实可用的调度扩展时才用它；无后端则说明不支持当前自动模式。`codex queue` 是消息入队接口，不是计时器。不得擅自安装系统 cron、systemd 服务，或把 `codex exec` 新会话当作当前会话。

## Hermes

当前会话简报优先使用 `/heartbeat every 2m <普通文本简报指令>`。使用宿主实际命令执行接口，不把斜杠命令当 shell 命令；模型没有命令入口时，转自然语言请求并核对结果。

先查询 `/heartbeat status`，保留已有其他用途心跳。无冲突时创建；修改使用同一会话设置入口并核对新的锚点；停止使用 `/heartbeat clear`（仅限所属心跳）；状态查询使用 `/heartbeat status`。最小间隔为 60 秒；每会话一个心跳；只在回合间空闲时触发，漏过周期会合并。

存在可用 `/loop` 且无其他用途循环时，可以使用固定周期 `/loop 2m <普通文本简报指令>`；先检查状态。它首次在下一空闲检查触发，随后按周期运行；停止 `/loop stop`。必须记录首报行为及 tick 上限，不默改用户预算。

`cronjob_manage` / `hermes cron` 依赖 gateway，通常每次创建独立会话，不作为上下文简报的默认后端。只有明确可读的进度来源和投递目标时才选择独立 cron；并检查 gateway 健康及实际投递。

## 其他 Agent：自然语言分配

使用宿主自身的任务控制入口，以自然语言请求执行，不预先硬编码 OpenCode 或其他工具的专门 API。把 N、任务和会话替换为实际值：

> 为当前任务及当前会话安排每 N 分钟一次的简报。回调采用所附完整简报规则。只管理标记为 reptlite 且属于本任务的调度。返回任务标识、启用状态、实际周期、下次触发时间及忙碌时的行为。若不支持、缺权限或无法投递，明确说明，不承诺已启用。

同样以自然语言请求修改所属任务周期、停止所属任务或查询所属任务。由实际工具结果确认执行；仅复述请求不是证据。没有调度入口时，直接提醒用户当前环境不支持自动模式，并保留 `/reptlite -i`。
