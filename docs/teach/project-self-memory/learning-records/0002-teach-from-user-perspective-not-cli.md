# 教程必须从使用者视角写，不从 CLI 视角写

第一版教程按命令表组织：init、validate、read、add、cache list……用户明确否定：「内容非常差劲，我需要补充使用 skill 的视角来使用的文档，当前的文档完全是 cli 视角」。

**Why**：用户是使用者，不是 CLI 调用者。「怎么用 project-self-memory」的真实问题是「我想让 agent 记住什么，我该说什么」，不是「这条命令的参数是什么」。命令表回答不了使用场景。

**How to apply**：教程正文按「你的意图」组织。每节给四样东西：你此刻想干什么、我该对 agent 说什么、它会替我做哪些事、我需要决定什么。用对话剧本呈现（你说什么 → agent 做什么 → 结果）。命令与参数退到附录，指向根 README 的参数速查。
