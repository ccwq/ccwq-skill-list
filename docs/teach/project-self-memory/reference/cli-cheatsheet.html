在 Codex 里敲什么

你想在 Codex 里输入等价的自然语言
处理暂存候选$project-self-memory -c「处理候选」「把攒的候选入库」
盘点经验$project-self-memory -g 或 -g 主题「盘点一下这次有哪些经验值得沉淀」
评分讨论$project-self-memory -r「评价一下这次用过的记忆」
清理过时结论$project-self-memory -t 或 -t 主题「清理一下已经过时的经验」
组合$project-self-memory -g -r「盘点并顺便评价」
显式读取$project-self-memory -l「把相关记忆列出来」
本次不读$project-self-memory --no-load「这次不读记忆」
本次不存$project-self-memory --no-save「这次不要保存」
本次不评分$project-self-memory --no-rate「这次不评分」
会话内持续关$project-self-memory --no-load-session「整个会话都不要读记忆」

CLI 命令

下表命令都在项目根目录执行。脚本路径固定为 .agents/skills/project-self-memory/scripts/memory.mjs。

你想要的命令输出
建库init文本 PSM_INITIALIZED
体检（闸门）validate文本 PSM_VALID / 失败退出 1
体检（报告）diagnoseJSON，恒退出 0。看 write_safe
读结论read人读文本
看目录catalog / catalog --by tagJSON
看单条详情inspect 0001JSON，含 record_version 与派生 tags
找待清理记录inspect --trim-candidatesJSON
新增结论add --type fact --content-file conclusion.txt文本：新 ID
改正文update 0001 --content-file revised.txt文本：ID。正文变了，评分清零（--keep-score 可保留）
改状态status 0001 review文本：ID
删记录delete --ids 0003文本 PSM_DELETED
合并两条merge --keep 0001 --remove 0002 --content-file merged.txt文本：保留的 ID
投票score 0001 +1 / score 0001 -1JSON 投影
清零评分score-reset 0001JSON 投影
修评分score-repair 0001 --positive 3 --negative 0JSON 投影。绝对值，不是增量
看候选cache listJSON，按 refid 分组，含失效与冲突标记
看单条候选cache show <event_id>JSON，含 base_content 与目标现状
候选入库cache apply --id <id> --decision writeJSON。改写后写入时加 --content-file
丢弃候选cache apply --id <id> --decision discardJSON
清历史条目cache prune --older-than 7dJSON。待处理的永不清理
手工塞候选cache add --op update --target 0001 --content-file p.txtJSON
看分类标准tags show / tags suggest / tags statsJSON，只读
改分类标准tags apply --plan-file taxonomy.jsonJSON。需具体授权
改单条标签tags set 0001 --add component:api --remove host_scope:tencJSON。需具体授权
看旧分组groups showJSON，只读
改旧分组groups apply --plan-file groups.json文本。计划须完整覆盖所有记录
扫旧格式库legacy scanJSON，含快照哈希
按计划迁入legacy migrate --plan-file plan.jsonJSON 数组，逐项成败

错误与退出码

输出前缀含义处理
PSM_ERROR通用失败，退出 1按消息定位参数或文件问题。
PSM_ERROR: PSM_CONFLICT乐观并发冲突：磁盘已被外部改动重读后重试。
PSM_ERROR: PSM_CONTRACT正文违反单行契约改成单行，不以标题、列表、围栏开头。
PSM_BACKUPstderr，非失败写库前的备份路径。
PSM_WARNINGstderr，非阻断例如 pending 积压超过 20 条。
