# ChatGPT Web Skill 统一经验累积机制规格

## 目标

将 `chatgpt-web-skill` 当前按版本、存放于临时目录的经验库，改为由脚本独占维护的统一经验库。经验永久存储在 `~/.config/chatgpt-web-skill/experience.md`；Windows 对应 `%USERPROFILE%\.config\chatgpt-web-skill\experience.md`。

不再按照 Skill 版本拆分经验文件。Skill 升级后，已有经验继续参与后续任务；版本变化仅触发友好 trim 提醒，不阻断任务。

## 存储边界

- 不枚举、读取、迁移、重命名或删除旧 `%TEMP%\chatgpt-web-skill-exp\` 经验文件。
- Markdown 是人工可读的存储格式，但读取、追加与整理只能经 `experience_memory.py` 完成。
- 经验文件头固定包含：

  ```markdown
  # chatgpt-web-skill 经验库
  Skill-Version: 1.15.0
  Entry-Count: 0
  ```

- `read` 在文件不存在时返回有效空库状态，且不创建文件。
- 首次 `append` 原子创建文件及八个预置分组。
- 每次读取重算实际条目数；文件头计数与实际值不一致时返回 warning。
- 所有写入使用原子替换及跨进程保护，避免并发丢失更新。

## 分组与条目

每条经验必须属于单层分组。预置分组为：

```text
浏览器会话
Project路由
消息提交
图片生成编辑
图片交付
视觉审查
Research
经验机制
```

- 追加时 `--group` 必填。
- 预置或已有分组可直接使用；新分组必须显式携带 `--create-group`。
- 条目以 `- [yy-mm-dd] 主题` 开头，日期由脚本生成。
- 条目包含场景、结论、边界，以及可选的最近核验日。
- 分组、场景、结论、边界经空白规范化后组成去重指纹；主题和日期不同不构成新经验。
- 重复追加保留最早主题和首次日期，更新最近核验日。

## 脚本契约

### `read`

新增 `read [--full]`，输出单个 JSON 对象：

- 当前 Skill 版本、文件记录版本、实际条数、文件头条数和 warning。
- 按分组有序返回经验。
- 默认精简模式只返回日期、分组、结论和边界。
- `--full` 额外返回主题、场景和最近核验日，供 trim 使用。
- 不返回 Markdown 标题、字段标签、列表符号或其他人类展示文本。

保留 `status` 作为兼容接口，只返回元数据与 warning，不返回经验正文。

### `append`

- 第一次追加创建文件；后续追加必须通过结构化解析和校验。
- 文件版本与当前版本不一致时，返回 `version_mismatch` warning 后仍允许追加，但不更新文件版本。
- 条目数大于 50 时返回 `experience_limit_exceeded` warning，仍允许追加。
- 文件头条数与实际值不一致时，返回 `entry_count_mismatch` warning 并拒绝普通追加。

### Warning

脚本仅返回稳定 warning code 与结构化上下文；调用 Agent 负责立即向用户给出中文友好提醒。

- 实际条数严格大于 50 时建议执行 `-t/--trim`，不停止当前任务。
- 文件版本不同于当前 Skill 版本时建议执行 `-t/--trim`，不停止当前任务。
- 计数不一致时读取返回实际数据和 warning；普通写入拒绝。

## `-t` / `--trim`

trim 通过 `read --full` 获取全量经验，由 Agent 对照当前 `SKILL.md`、脚本和 references 识别：已内化、过时、冲突、重复或本轮未证实的经验。

- 按分组讨论保留、改写、合并、删除或本轮未证实，并说明当前证据。
- 删除、改写、合并必须具备已验证证据。
- 用户最终明确回复 `ok` 后，脚本才接受计划并原子写回。
- 计划必须恰好覆盖每条原始经验一次，不能遗漏或重复处理。
- trim 可修复条目计数不一致。
- 只有全库 trim 成功，才把文件中的 `Skill-Version` 改为当前 Skill 版本，并重算 `Entry-Count`。
- 普通任务与追加不能提前更新文件版本。

## 验收

- 经验机制使用 `experience_memory.py` 命令级行为作为最高测试接缝，不依赖浏览器。
- 测试使用临时配置目录和固定日期，绝不读写真实用户经验库。
- 覆盖 Windows 与 POSIX 路径、旧临时目录不被访问、缺失文件读取无副作用、首次追加创建文件。
- 覆盖预置分组、自定义分组显式创建、日期格式、精简与完整 JSON 输出及展示内容过滤。
- 覆盖去重、最近核验日更新、50/51 条 warning、版本不一致时读取和追加。
- 覆盖计数不一致时的读取 warning、追加拒绝和 trim 修复。
- 覆盖 trim 的计划完整性、证据要求、保留/改写/合并/删除、全库完成后的版本更新，以及原子写入/并发保护。
- 每个新增或修改测试用例前添加中文 Given/When/Then/防回归注释。
- 最终运行完整 Skill 测试、Python 编译、marketplace JSON 校验、README 链接校验和 `git diff --check`。

## 非目标

- 不自动迁移或清理旧临时经验文件。
- 不在升级、读取或普通追加时自动删除经验。
- 不支持嵌套分组、多分组条目或隐式创建自定义分组。
- 不因版本不一致或条目超过 50 而阻断正常 ChatGPT Web 任务。
- 不改动浏览器路由、Project 设置、视觉审查、图片生成或下载行为。
- 不包含提交、push 或发布流程。
